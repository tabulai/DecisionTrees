# Demo Notebooks

These notebooks are designed to be read in order:

1. `01_classical_cart_pruning.ipynb` introduces CART growth and
   cost-complexity pruning.
2. `02_ensembles_random_forest_boosting.ipynb` compares single trees,
   bagged/randomized tree ensembles, and boosted decision trees.
3. `03_split_criteria_id3_cart.ipynb` computes entropy, information gain,
   gain ratio, Gini impurity, and threshold search directly.
4. `04_hoeffding_tree_stream_demo.ipynb` illustrates Hoeffding-bound split
   commitment for streaming tree induction.

All notebooks use synthetic datasets so they can run without downloading data.
