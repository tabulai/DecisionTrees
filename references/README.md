# Reference Audit

Audit date: June 6, 2026.

This directory contains the curated literature base for the decision-tree
algorithm report:

- `manifest.csv` - compact spreadsheet-friendly reference list
- `manifest.json` - JSON reference manifest
- `bibliography.bib` - BibTeX bibliography

The manifest is restricted to decision-tree algorithms and tree-specific
ensemble algorithms. It includes classical induction, split criteria, pruning,
oblique and model trees, scalable tree construction, random forests, boosted
decision trees, optimal sparse trees, Bayesian tree ensembles, specialized
forests, anomaly-detection trees, and streaming trees.

Citation keys in `deep-research-report.md` match the `id` column in
`manifest.csv` and the BibTeX keys in `bibliography.bib`.
